The product

One endpoint. Pay per answer.
A receipt with sources.

  • POST /verify — agent asks: "Did example Corp disclose audited revenue by deadline?" + resolution criteria
  • 402 Payment Required — x402 V2 terms: 0.01 USDC-equivalent, network solana:EtWTR…
  • Pay on Solana — client deposits into an Anchor escrow PDA; the server verifies the deposit on-chain
  • Truth Receipt — outcome (YES/NO/UNDECIDED), confidence, evidence URLs, deposit signature, escrow status

verification-oracle05
The AI pipeline

Grounded answers, not vibes

  • TinyFish Search — ranked live web results, allowlisted domains only (bbc / espn / reuters / ap)
  • TinyFish Fetch — clean page-text extraction (JS-rendered pages included)
  • Groq · openai/gpt-oss-120b — reasons YES/NO/UNDECIDED + confidence from the evidence
  • Gemini fallback — automatic on Groq rate-limit
  • Confidence < 0.5 ⇒ forced UNDECIDED — the escrow becomes refundable, not claimed

Every receipt ships the cited evidence URLs — judges can click them.

Operator side

Settle anything in one signature

  • Dashboard lists one row per deposit transaction: short signature, explorer link, nonce, attested badge
  • Batch claim — tick N checkboxes → one transaction, N claim instructions (≤4 per tx, auto-split beyond)
  • Attestation gate: unattested deposits show ⚠ attestation pending, claim is hidden, refund stays available
  • Depositor refunds from CLI: npm run refund -- <nonce> — refund never depends on attestation
